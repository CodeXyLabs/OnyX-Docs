OnyX Code

OnyX Code — локальный ИИ-ассистент для Windows и Android. Нейросеть работает на вашем устройстве: диалоги не уходят в облако, интернет нужен только для скачивания моделей и (по желанию) веб-поиска. Приложение умеет общаться, создавать файлы, собирать отчёты, презентации, таблицы и планы.

🖥 Windows

Полноценное приложение с боковой панелью, историей чатов, файловым агентом и генератором PowerPoint. Требует установленный локальный движок Ollama.

📱 Android

Мобильная версия со встроенной моделью в APK (работает сразу после установки) и возможностью скачать более мощные модели. Движок собран под arm64 и x86_64.

🧠 Онлайн-версия (в разработке)

Будущий режим без локальных моделей.

1 Установка · Windows

Что нужно

  • Windows 10/11 (64-бит).
  • Ollama — локальный движок нейросетей. Скачивается с ollama.com, устанавливается в %LOCALAPPDATA%\Programs\Ollama.
  • Дистрибутив OnyXCode-Setup.exe.

Порядок

  1. Установите Ollama и один раз запустите его (в трее появится значок).
  2. Запустите OnyXCode-Setup.exe и следуйте мастеру.
  3. Откройте OnyX Code: при первом запуске появится заставка, затем окно входа.
  4. Войдите через Google или пропустите вход.
При первом использовании приложение само скачает выбранную модель через ollama pull (кнопка «Проверить» в настройках показывает статус). На это нужно время и место на диске.

Вход через Google

На десктопе используется OAuth-флоу с локальным callback-адресом http://127.0.0.1:53000/. После нажатия «Продолжить» откроется браузер; после подтверждения вход завершится автоматически.

2 Установка · Android

Что нужно

  • Телефон Android 11+ (API 30).
  • Файл OnyXCode.apk (содержит встроенную модель — размер около 500 МБ).
  • Для мощных моделей — ~2–9 ГБ свободного места.

Порядок

  1. Скопируйте APK на устройство и откройте файл (подтвердите установку «из неизвестных источников», если попросят).
  2. Запустите OnyX Code. При первом старте из APK автоматически разворачивается встроенная модель OnyX Mini (около 470 МБ) — интернет не нужен.
  3. Выберите «Продолжить без аккаунта» или войдите через Google.
Благодаря встроенной модели приложение работает полностью офлайн сразу после установки. Более качественные модели скачиваются из каталога (раздел «Модели»).

Вход через Google (Android)

В мобильной версии вход выполняется через встроенный WebView: открывается страница Google, после входа код авторизации перехватывается автоматически. Если вход отклоняется, настройте Web Client ID:

  1. Google Cloud Console → «OAuth consent screen» → «Credenciales» → создать клиент типа Web application.
  2. Скопируйте Client ID (вида xxxx.apps.googleusercontent.com).
  3. Вставьте его в приложении: меню ⋯ → «Настройки» → «Вход через Google» → сохранить.

Без настройки клиента можно пользоваться приложением локально («Продолжить без аккаунта»).

Выбор и скачивание (Android)

  • При первом запуске или из меню «Модели» выбирается активная модель.
  • Кнопка «Скачать» скачивает модель с Hugging Face (прямые GGUF-файлы); есть прогресс, докачка и отмена.
  • Скачанные модели помечаются «Скачана», активная — «Выбрана · работает на устройстве».
  • Встроенную Mini нельзя удалить — можно только выбрать.

Автопроверка при запуске

При старте чата модель проверяется и «прогревается»: статус в шапке меняется с «подготовка модели…» на «готова · название модели». Это уменьшает задержку первого ответа.

Модели 7B–8B требуют 6–8 ГБ свободной оперативной памяти. На слабых устройствах пользуйтесь Mini/Lite.

4 Чат

Как общаться

  • Введите сообщение в поле ввода и нажмите ➤ (или Enter на ПК; Shift+Enter — новая строка).
  • Пока модель отвечает, кнопка отправки превращается в ■ — нажмите её, чтобы остановить генерацию.
  • Система говорит обычным языком: пишите как человеку — «создай файл», «составь план», «объясни простыми словами».

Элементы экрана

ЭлементНазначение
☰ (слева вверху)Меню: новый чат, история, модели, настройки, выход.
Точка статуса + текст«готова», «подготовка модели…», «OnyX думает…».
🌐 / «Поиск»Включить веб-поиск — модель использует данные из интернета.
«Рассуждение»Режим объяснения хода мыслей перед ответом.
«⧉ Копировать»Под каждым сообщением — копия текста в буфер.

История чатов

  • Все беседы сохраняются автоматически (на ПК — %LOCALAPPDATA%\OnyXCode\chats.json; на Android — в файлах приложения).
  • «+ Новый чат» создаёт пустую беседу; «История чатов» открывает прошлые.
  • Удаление беседы — через меню или долгое нажатие (требует подтверждения).

5 Файлы и агент

OnyX умеет создавать, читать, показывать и удалять файлы — для этого не нужны технические команды. Достаточно попросить по-русски:

  • «Создай файл заметка.txt с текстом …»
  • «Запиши план в файл»
  • «Что в моих файлах?» / «Покажи папку»
  • «Удали файл старое.txt»

Куда сохраняются файлы

ПлатформаПапка
AndroidЗагрузки/OnyX (видно в файловом менеджере; дубликат во внутренней папке приложения)
WindowsДокументы/OnyX Code/…

Как это устроено

Модель общается с приложением служебными блоками вида <<<CREATE path="файл">>> … <<<END>>>. Понимаются также SAVE, WRITE, FILE, APPEND, READ, LIST, DELETE. Вы сами эти блоки не видите — видите только результат и короткую подпись «Файл: …».

Создание и изменение файлов выполняется сразу (вы дали согласие, открыв ассистента). Удаление всегда проходит через подтверждение — случайно стереть нельзя.
Выход за пределы рабочей папки запрещён (безопасность): система не трогает системные каталоги.

Готовые инструменты вызываются кнопками на пустом экране: Отчёт, Презентация, Таблица, План. Откроется окно, где вводится тема, затем нажмите «Выполнить».

7 Веб-поиск

Когда веб-поиск включён, перед ответом модель получает свежие результаты из интернета (поиск через DuckDuckGo, без API-ключей) и отвечает с их учётом. Это полезно для вопросов о текущих событиях, ценах, датах, новостях.

Как включить

  • Кнопка 🌐 в шапке чата (становится красной при включении).
  • Или чип «🌐 Поиск» над полем ввода.
Результаты поиска — справочные и могут быть устаревшими. Проверяйте критичные факты.
Для веб-поиска нужен интернет; построенные модели отвечают медленнее.

8 Лимиты и активация

Без активации доступно 10 запросов в день (счётчик сбрасывается каждые сутки). Активация снимает лимит:

КодСрок
PERM-…Навсегда
YEAR-…На год
MONTH-…На месяц

Код вводится в меню «Активировать» (или «Сменить код»). После активации в боковой панели появляется статус «Активировано навсегда · Без ограничений» с зелёной полосой лимита.

Раздел «Настройки» (меню ⋯) позволяет:

  • Модель OnyX — выбрать активную из каталога; «Проверить» — проверить доступность и прогреть; «Журнал» — посмотреть/очистить журнал приложения.
  • Вход через Google — указать Web Client ID для входа (Android).
  • Параметры генерации:

  • Для коротких строгих ответов: температура 0.1–0.3.
  • Для креативных текстов: 0.7–1.0.
  • На слабых устройствах уменьшите «Размер контекста» и «Макс. токенов».

10 О нейросети OnyX

Что это

OnyX — самостоятельная нейросеть, которая исполняется локально через движок llama.cpp. Модель «живёт» на вашем устройстве: документы и переписка не покидают его.

Как работает

  1. Вы пишете сообщение.
  2. Приложение формирует промпт (инструкция ассистента + ваш вопрос, при необходимости + результаты веб-поиска).
  3. Движок llama.cpp генерирует ответ токен за токеном на CPU.
  4. Ответ показывается в чате; если модель вернула файловые блоки — они выполняются.

Правила хороших промптов

  • Будьте конкретны: «Составь план запуска кофейни из 5 шагов» — лучше, чем «помоги с бизнесом».
  • Укажите формат: «в виде списка», «таблицей», «кратко», «подробно».
  • Дайте контекст: цель, аудитория, ограничения.
  • Просите файл явно: «создай файл план.md» — тогда будет создан файл.
  • Разбивайте большие задачи на части.

Возможности

Диалог на русском Файлы Отчёты Презентации .pptx Таблицы .csv Планы Веб-поиск Офлайн-работа Безопасность данных

Ограничения

  • Модели малого размера (Mini/Lite) могут ошибаться в фактах; проверяйте важную информацию.
  • Локальный запуск на CPU: скорость зависит от устройства; размер контекста ограничен памятью.
  • Генерация презентаций/файлов зависит от того, насколько точно модель следовала формату.

11 FAQ и неполадки

«Локальный движок не отвечает» на Windows

Убедитесь, что запущен Ollama (ollama serve или значок в трее). В настройках нажмите «Проверить». Если модель не установлена — приложение само предложит ollama pull.

«Модель не скачана» на Android

Откройте «Модели» и нажмите «Скачать» у нужной модели. Встроенная Mini не требует скачивания — выберите её.

Вход через Google не работает

На Android укажите Web Client ID в «Настройки → Вход через Google» (см. раздел 2). Проверьте интернет и что аккаунт Google добавлен в систему. Всегда доступен локальный режим «Продолжить без аккаунта».

«Ошибка модели» / «No group 2» (старые версии)

Обновите приложение. В версии 3.2 устранены зависания второго запроса и ошибки парсера; модели отвечают последовательно.

Медленные ответы

Выберите меньшую модель (Mini/Lite), уменьшите «Макс. токенов» и «Размер контекста», включите больше «Потоков» (если позволяет CPU).

Не хватает памяти

Модели 7–8B требуют 6–8 ГБ RAM. Закройте тяжёлые приложения или используйте Mini/Lite.

Где файлы?

Android: Загрузки/OnyX. Windows: Документы/OnyX Code/…. Путь всегда выводится в чате после создания файла.
